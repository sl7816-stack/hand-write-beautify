# 書法字體向量化與數位化工具 (Calligraphy Digitization Tool) - v0.36

> 前端矢量化架構升級與參數標準化，提供高解析度放大不失真的字體擷取體驗。

## 📌 版本簡介

v0.36 版本對系統底層進行了核心重構，導入前端 **Potrace** 矢量化引擎，解決了過往點陣圖放大後的鋸齒問題。同時針對參數控制與檔案輸出機制進行全面優化，顯著提升了圖片下載效率與使用者操作體驗。

## 🚀 核心更新亮點 (Key Features)

### 1. 前端 Potrace 向量化 (v0.36-a)
- **向量級放大**：採用 Potrace 引擎直接於前端將點陣圖轉為 SVG/矢量結構，確保文字在任何尺寸下均保持銳利無鋸齒。
- **渲染效能優化**：減少對後端圖像處理的依賴，大幅提升即時預覽速度。

### 2. 參數控制與控制項分層 (v0.36-c / v0.36-f / v0.36-g)
- **統一參數標準**：將所有調整控制項（如對比度、臨界值、去噪等）統一轉化為 **0 - 100** 的直覺數值範圍。
- **友善介面設計**：針對高齡與入門使用者重新設計 UI，區分「常用控制」與「進階設定」，簡化操作流程。

### 3. 多階檔案輸出下載 (v0.36-d)
- **檔案大小分級**：提供不同解析度與容量梯度的下載選項，滿足列印、網頁展示或排版等多樣化需求。
